# litereader
Minimal Terminal E-book Reader

## Controls

| Key | Action |
|-----|--------|
| `n` / `l` / `Space` / `→` / `↓` | Next page |
| `p` / `h` / `Backspace` / `←` / `↑` | Previous page |
| `g` | Jump to first page |
| `G` | Jump to last page |
| `:<number>` `Enter` | Jump to a specific page number |
| `q` / `Q` | Quit |


## Requirements

pdftotext, mutool or ps2ascii
